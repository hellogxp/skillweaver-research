# Historical reference results

Files in `reference/` preserve selected historical artifacts. They were not generated by rerunning neural models for this release. Version identifiers in filenames distinguish the original experiments.

| Artifact group | Meaning / limitation |
| --- | --- |
| `main_results_v4`, `convergence_v4`, `transfer_v4` | SAD, iterative, and held-out experiments; skill transfer evaluates 100 of 139 eligible queries |
| `compose_eval_detailed`, `sad_subtask_texts` | Compose evaluation and recorded SAD decompositions; chain-derived edge labels |
| `encoder_baselines`, `compat_validation` | Encoder comparison and LLM-judged compatibility |
| `cross_model_14b`, `paraphrase_v4`, `paraphrase_expanded` | Cross-model/paraphrase results; some files contain aggregates only |
| `constrained_vanilla_oracle_k`, `llm_rerank_d1_300` | Oracle-step-count control and full-benchmark reranking |
| `baselines_v4` | Baseline metrics; complete qwen-max inference runner unavailable |
| `human_queries_v2`, `human_queries_v2_breakdown` | 200-query metrics; original input/annotation file unavailable |
| `human_queries_v4`, `human_compose_eval` | Separate 50-query legacy evaluations |

New experiment outputs default to `runs/`. Keep them separate from these references. Do not mix the 50-query results with the 200-query claims or infer unavailable query text from metric arrays.
